1. touch file_name  --> create an empty file

2. echo "hello' > hello.txt 
   echo "hello' >> hello.txt

   > vs >> used in echo 

   > --> used for overwrite
       i) create hello.txt if it doesnot exist
       ii) if the file is already existing and have the content , old content is deleted/replaced .


       >>  ---> Append

       i) create hello.txt if it doesnot exist
       ii) if the file already existing is will append hello at last
